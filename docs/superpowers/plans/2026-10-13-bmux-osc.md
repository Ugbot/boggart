# BMUX-17: typed terminal events

Port the pinned OSC parsers into a bounded C command parser, then connect it to
the native terminal event sink and a Lua queue drained at batch boundaries.
Shell bytes are untrusted; they produce typed data, never shell/file/network
actions. Clipboard read/write policy defaults to deny and survives terminal
reset. Consumers must check policy before applying queued clipboard requests.

- [x] Validate and test OSC 0/2/7/8/9/99/777/133/52 in `src/bosc.c/h`, preserving
  pinned source attribution. Include malformed UTF-8, controls, invalid URIs,
  base64, unsupported metadata and bounded payloads.
- [x] Wire a C event sink (including bell), clipboard policy, bounded Kitty
  title/body chunk assembly and Lua event draining. Verify whole/fragmented
  event order and queue overflow without stopping normal terminal output.
- [x] Publish drained typed events with pane identity to the existing bus.
  Test actual subscribers and permission revocation before drain.
- [x] Store OSC 8 links with cell/history ownership, reclaim unused link IDs,
  and expose URIs to snapshots/rows. Verify edits, alternate screens and eviction.
- [x] Build both front ends, run relevant sanitizers/full suite/parity, update
  the port ledger and tracker with evidence, and commit verified increments.

BMUX-17 is complete only when typed events reach bus subscribers, clipboard
requests are gated, and links survive with their cells. Live PTYs remain
BMUX-21; notification UX and native notification delivery are later tickets.
Kitty notification extensions must be advertised only when implemented; plain
title/body chunks are the required notification path here.
