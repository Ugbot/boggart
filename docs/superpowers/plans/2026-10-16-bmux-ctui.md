# Native Bmux terminal client

Continuation of the approved shared-layout client design, BMUX-35/84.

The server owns the hierarchy and PTYs. Studio and the terminal client consume
the same validated snapshots and native attachment/control protocol. Ctrl-B
introduces visible commands; narrow windows display the focused pane without
changing the server tree. Input control is explicit and lease based.
